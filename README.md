# React Compiler workshop

The repository for WebExpo 25 workshop. Using Next.js.

## Getting Started

First, install the dependencies:

```bash
yarn install
```

## Available Scripts

In the project directory, you can run:

- `yarn dev` - Starts the development server with Turbopack
- `yarn build` - Builds the app for production
- `yarn start` - Runs the built app in production mode
- `yarn lint` - Runs ESLint to check for code issues
- `yarn pretty` - Checks code formatting with Prettier
- `yarn pretty:fix` - Automatically fixes code formatting issues

## Development

The project uses:

- Next.js 15.2.4 with React 19
- TypeScript for type safety
- Tailwind CSS for styling
- ESLint and Prettier for code quality
- React Compiler (experimental) for improved performance

To start developing, run:

```bash
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

> **Note**: React Compiler profiling and debugging features are only available in development mode (`yarn dev`). These features are not available in production builds (`yarn build` and `yarn start`).

## Features

- Modern React with React 19
- TypeScript support
- Tailwind CSS for styling
- Component library with Radix UI
- Code quality tools (ESLint, Prettier)
- React Compiler for improved performance
